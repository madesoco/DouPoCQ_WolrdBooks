# DouPoCQ_WolrdBooks

《斗破苍穹》SillyTavern 世界书项目。

本仓库仅发布《斗破苍穹SP》相关内容。

## 仓库内容

```text
DouPoCQ_WolrdBooks/
├── README.md
├── 斗破苍穹SP.yaml    # 世界书总入口与条目配置
└── 斗破苍穹SP/        # 世界书条目、变量、脚本及前端源文件
```

## 使用说明

- `斗破苍穹SP.yaml` 负责组织世界书条目的顺序、启用状态及源文件路径。
- `斗破苍穹SP/` 保存该世界书使用的公开源文件。
- 使用支持该 YAML 项目结构的工具进行编辑、构建或导入。

## 发布约定

本仓库只跟踪并推送以下路径：

- `斗破苍穹SP/`

本地草稿、原文、工作记录、模板、同步配置及辅助工具均不属于本仓库发布内容。
